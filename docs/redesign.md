# ArtStudio — редизайн

Новое направление — контрастное персональное портфолио. Графит, холодная типографическая бумага, один лаймовый акцент. Onest для заголовков и основного текста, IBM Plex Mono для индексов и подписей. Hero показывает работу «В сторону сада». На главной сразу после него начинается редакционная подборка. У каждого проекта сохраняется маркировка «Концепция».

Первый цикл включает аудит прежних скриншотов, изменения композиции, маски и переходы. Второй цикл проверяет опубликованную сборку, маршруты и контрольные размеры через VPS Playwright.

Skills по этапам — frontend-design и ui-ux-pro-max для композиции, GSAP Core/React/ScrollTrigger/Timeline/Performance для движения, Vercel React Best Practices для границ клиента, Web Design Guidelines и Playwright для приёмки. Отдельного Accessibility Skill в каталоге нет, применены семантические и клавиатурные проверки.
