## Ревью и доработки

Независимое статическое ревью проверило маршруты, форму, SEO, клавиатурный фокус и адаптивную сетку. Доработаны высота десктопного hero до 92svh, отдельное мобильное кадрирование, ширина одиночной портретной карточки, порядок заголовков, возврат фокуса из пустого архива, контраст рамок полей и метаданные. Для формы добавлен тест с публичным Origin и внутренним адресом Next.js. Устранены ошибки первого билда: импорты Manrope сверены с exports установленного пакета, опциональные свойства полей описаны явным типом.

Вручную просмотрены исходные визуализации и мобильная производная. Браузерный самотест `t3browser` прошёл под UID 991 с sandbox. При доступе к локальному production-маршруту напрямую приложение ответило 200. Через прокси `t3browser` тот же URL получил 403 на обоих viewport.

| Viewport | Run ID | Результат |
|---|---|---|
| 1440×900 | `08001177-8fdc-4f08-9abe-08cfbac41304` | Прокси HTTP 403, DOM и скриншот страницы не получены |
| 390×844 | `3a2e20b0-3ee8-433a-b437-28d1a98379bf` | Прокси HTTP 403, DOM и скриншот страницы не получены |

Отчёты runner сохранены в `artifacts/qa/`. Документированный VPS offline-fixture регистрирует фиксированные входы игры C01 и для этого проекта не применялся. Два браузерных цикла, проверка tablet/360px, мобильные свайпы, фокус галереи и меню, консоль, фактическая отрисовка веб-шрифтов, визуальный контраст hero и Core Web Vitals остаются открытыми. HTTP smoke проверяет полученный HTML и ресурсы без исполнения клиентских сценариев. Фактическая доставка в сервис владельца также требует настройки.
